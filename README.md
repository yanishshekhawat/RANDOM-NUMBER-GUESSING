# RANDOM-NUMBER-GUESSING
GUSSING RANDOM NUMBERS
Random Number Guessing Game Using C Programming

Project Description

The Random Number Guessing Game is a simple, interactive console-based application developed using the C programming language. In this game, the computer generates a random number between 1 and 100, and the player has to guess the correct number.

After each guess, the program provides hints:

- Too Low: The guessed number is smaller than the secret number.
- Too High: The guessed number is greater than the secret number.
- Correct Guess: Displays a congratulatory message and the total number of attempts.

The game continues until the player guesses the correct number.

Features

- Generates a random number between 1 and 100.

- Counts the number of valid attempts.
- Checks for invalid number ranges.
- Simple and beginner-friendly interface.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in your C compiler or terminal.
3. Compile the source code using GCC:

gcc guessing_game.c -o guessing_game

4. Run the program:

Windows:

guessing_game.exe

Linux/macOS:

./guessing_game
